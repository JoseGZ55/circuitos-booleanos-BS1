== Ejemplos de mensajes de error ==
  ""         La expresión está vacía. Escriba una función, por ejemplo: X'Z + XY'
  "   "      La expresión está vacía. Escriba una función, por ejemplo: X'Z + XY'
  "X +"      Posición 4: la expresión termina de forma incompleta después de '+'; falta una variable o un paréntesis.
  "X ++ Y"   Posición 4: se esperaba una variable o '(' después de '+', pero se encontró '+'.
  "+X"       Posición 1: se esperaba una variable o '(', pero se encontró '+'.
  "'X"       Posición 1: el apóstrofe (') debe ir inmediatamente después de una variable o de un ')', por ejemplo X' o (X+Y)'.
  "X..Y"     Posición 3: se esperaba una variable o '(' después de '.', pero se encontró '.'.
  "(X+Y"     Posición 1: el paréntesis '(' abierto aquí nunca se cierra; falta ')'.
  "X+Y)"     Posición 4: el paréntesis ')' no tiene un '(' que le corresponda.
  "X()"      Posición 3: hay paréntesis vacíos "()".
  "xY"       Posición 1: las variables se escriben en mayúscula; use 'X' en lugar de 'x'.
  "A+B"      Posición 1: la variable 'A' no está permitida. Use solo W, X, Y o Z.
  "X & Y"    Posición 3: el carácter '&' no es válido. Use variables (W, X, Y, Z), ' para negar, + para OR, . o yuxtaposición para AND, y paréntesis.
  "(X+)Y"    Posición 4: se esperaba una variable o '(' después de '+', pero se encontró ')'.
